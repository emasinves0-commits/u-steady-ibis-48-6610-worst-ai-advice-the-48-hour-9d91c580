# Worst AI Advice: The 48-Hour Tight Line Open

An entry for the [make.fun bounty](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) "Worst AI Advice: The 48-Hour Tight Line Open".

The program writes exactly one line — 86 characters, no trailing newline — to `/output/entry.txt`:

> To find a gas leak, hold a lit match near the pipe and watch for the flame to flicker.

Run it with Node 22 (TypeScript): `npx tsx main.ts` (or compile with `tsc` and run the output). The entry line is deliberately terrible advice — that is the point of the bounty.
