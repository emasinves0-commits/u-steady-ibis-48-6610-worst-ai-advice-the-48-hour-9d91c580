# Worst AI Advice: The 48-Hour Tight Line Open

An entry for the [make.fun bounty](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) "Worst AI Advice: The 48-Hour Tight Line Open".

The program writes exactly one line — 121 characters / 123 bytes (UTF-8), no trailing newline — to `/output/entry.txt`:

> For the freshest breath, gargle with bleach for 10 seconds — it kills 99.9% of germs, and the burning means it's working.

Run it with Node 22 (TypeScript): `node main.ts` (Node 22.18+/24 strips types natively) or `npx tsx main.ts` (or compile with `tsc` and run the output). The entry line is deliberately terrible, obviously unsafe satire — that is the point of the bounty. Do not follow it.

`main.ts` validates the line (1-140 characters, not only whitespace) before writing, and the output is byte-identical on every run.
